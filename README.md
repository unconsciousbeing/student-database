# Student Database Project

A Python command-line application for storing and managing student records using CSV files.

## Features

* Add students
* Search students by name or roll number
* View all student records
* Remove student records
* Update student marks
* Sort students by name or marks
* Find the class topper
* Calculate average marks

## How to Run

Make sure Python is installed, then run:

```bash
python main.py
```

The program will open in the terminal and provide a menu of available operations.
